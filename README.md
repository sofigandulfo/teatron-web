# Teatron Web 🎭

Sistema de reserva de asientos en tiempo real para eventos teatrales.

🔗 **Demo:** [teatron-web.vercel.app](https://teatron-web.vercel.app)

## Funcionalidades
- Reserva de asientos con actualización en tiempo real
- Envío de mails a los usuarios

## Tecnologías
React · Firebase · CSS · Vercel

## Cómo correrlo localmente
```bash
npm install
npm start
```
